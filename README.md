# discord-presence
Удобное приложение для настройки Discord Rich Presence: задавайте собственный текст активности и изображение, управляйте статусом в несколько кликов и находите секретную мини-игру. Не требует Node.js для установки. Для работы нужны Discord для компьютера и собственный Application ID из Developer Portal.
# Discord Presence

Простое настольное приложение для настройки Discord Rich Presence. Оно использует локальный RPC-интерфейс Discord, не изменяет клиент и не автоматизирует учетную запись.

## Установка для Windows

Запустите `Discord Presence Setup.exe`: установка пройдёт автоматически, после неё приложение откроется. В окне задайте текст и ключ картинки, сохраните настройки и нажмите «Запустить». В дальнейшем приложение можно открыть через ярлык на рабочем столе или в меню «Пуск».

Откройте Discord для компьютера и оставьте его запущенным. Вставьте Application ID приложения из [Discord Developer Portal](https://discord.com/developers/applications). Картинку загрузите в **Rich Presence → Art Assets** и укажите ее ключ (имя), а не путь к файлу на компьютере. Название активности берется из названия приложения в Developer Portal.

Настройки хранятся отдельно от программы в папке данных пользователя Windows.

Для собственного Application ID и картинки потребуется один раз создать приложение и загрузить изображение в Developer Portal. Установщик не подписан цифровым сертификатом, поэтому Windows может показать предупреждение SmartScreen.
